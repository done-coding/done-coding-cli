created: 2026-11-21
from: dotfiles

## 现象

`dc-harness lists` 生成的 `ARCHIVE-DONE.md` 只有三列：批次、所涉领域、交付记录链接；行按批次目录名（随机 id）的字母序排列。批次进度文件头部有 `created`，但清单里不出现，也没有归档时间。

想找「某个领域最近交付的几批」时，清单给不出先后，只能逐个打开进度文件看日期或查 git 历史。

## 复现路径

1. 任一启用治理目录且有多条归档的仓（如 `~/.dotfiles`，30 余条）运行 `dc-harness lists --dir docs/governance`。
2. 打开 `ARCHIVE-DONE.md`：首行是 `0rtp5k-…`，末行是 `ylnmj0-…`，与交付先后无关。

## 期望（供分诊参考）

清单带一列日期并按时间倒序。日期取哪个（进度文件的 `created`，或归档提交的时间）由本仓定；注意清单不能含会随时间变化的计算值，否则「重生成零 diff」的闸会恒红。
